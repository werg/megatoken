# One observed late callback

The native bounded coordinator can explicitly admit one retained subscription callback after its single root has completed and published its return. The coordinator must still be active, have one active-track allowance, and have no pending candidate. Exactly one observed event and its callback invocation must extend the acknowledged public prefix. Independent native replay establishes source, handler, closure, parent, realm and observed input. A caller cannot supply a replacement child binding or captured heap. The general dynamic-invocation refusal remains for every unadmitted invocation.

Admission is an observed operation in ordered checkpoint replay. It consumes no model selection, creates no native child track and executes no callback. Ordinary create, acknowledged bootstrap, issued join and typed completion remain necessary. Exact admission retries return the original receipt; changed input/history refuses. A second late callback is outside this profile.

Guarded sessions route admission through the existing durable commit journal. A separate before/after audit independently derives the one allowed child and operation, preserving unrelated sessions, attempts, model identity, randomness and completed work. Known recorded outcomes reconstruct the whole native adapter with zero host dispatches. Missing or unknown outcomes never become permission to execute or redispatch.

The private ingress journal is an independent producer boundary. Public event rows do not contain private arrival arguments. Native validates the resulting public invocation and binds its input graph; the producer must independently compare the recorded arrival to that observed input on restoration. Producer integration is pending on this native source increment. No successor-owner transition, perpetual callback stream, source-admission qualification, default cutover or learned execution is claimed.
