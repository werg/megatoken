# Source-qualified V8 coordinator training

An admitted V8 source artifact may contain one independently checked
`semantic-orchestration-transcript/1`. It teaches a bounded coordinator to
create one declared child, join its issued completion dependency, publish the
child's exact result, and complete. The child retains its original public
execution and semantic targets. These authored targets are teacher evidence;
they are not model-selected execution or a learned-quality result.

## Authority and causal inputs

The producer attaches the transcript only after repeating original-source,
projection and public-replay checks. The native validator reconstructs its
contexts, lifecycle registry, issued dependency, exact child result and heap,
and all ten transcript events independently. A source receipt must name the
hash of the **complete transcript, including its own internal digest**.
Dataset bindings and native admission receipts bind that same hash.

The initial coordinator observation contains only the original source and
input prefix. Child completion and later generated history cannot appear in
that initial observation. Creation is followed by a separate bootstrap:
the child observes exact copies of its source and input before the coordinator
observes the bootstrap receipt. Native completion delivery precedes the typed
child-completion observation. Each target follows its exact causal context.

The teacher's acknowledgement retains schema
`semantic-orchestration-teacher-commit/1`. Actual native API acknowledgements
retain `semantic-orchestration-commit/8` and their original selection IDs.
Both paths expose the same neutral `semantic-orchestration-ack-observation/8`
prediction input; a teacher never invents native selection IDs or model tokens.

## Ordinary physical records

Preparation emits four loss-bearing lifecycle targets on coordinator
`track:0`. The child's original semantic targets and observations belong to
`track:1`. Each physical part retains its actual owner, role, payload, policy
mask and initial or continuation instruction. Long records use the normal
bounded physical framing and the same request-control builder as serving.

The content digest binds physical bytes and token labels, track specifications,
instructions, provenance, action/receipt ownership and dependency edges. The
ordinary training policy rebuilds the full episode from its retained source
artifact; receipt presence alone is insufficient. The `semantic_child` behavior
census requires the actual lifecycle rows, exact source/native receipt bindings,
four registered actions, and their physical causal order. A parent pointer or
detached annotation cannot satisfy this behavior.

## Work budgets and supported scope

The policy charges one unit per complete authored target. Four coordinator
targets consume four units from an initial 100,000; the child starts at 64 and
consumes one unit for each original semantic target. More than 64 child targets
is refused. Actual serving consumes model fragments, which may divide a target
differently. Logical teacher work and actual model fragment cost are separate
quantities; this implementation does not assert their general equivalence.

This teacher supports one declared root, no new invocations after ingress, and
an exact terminal child completion. It does not authorize dynamic descendants,
arbitrary callbacks, uncontrolled effects, or broader production coverage.
Child-only and augmented artifacts have distinct episode identities while
retaining their common source-family split.

## Qualification

The paired workflow retains its existing ordinary semantic lifecycle and adds
a separate producer command with `--orchestration-teacher`. It runs fresh source
admission, ordinary preparation, one optimizer update, fresh-process resume for
a second update, export, and actual coordinator token selection and service
restoration. The collector reads the saved physical records and verifies all
four logical lifecycle targets. It leaves per-target optimizer exposure and
learned success unmeasured; two updates do not imply every target was consumed.

Local model-free controls cover physical owner/control parity, persisted policy
rebuild, causal-order tampering, source/native receipt boundaries and the saved
corpus collector. Their explicitly injected source/tokenizer audit receipts and
byte-fallback codec are test boundaries, not production admission. The larger
predeclared ordinary source also passes fresh original-source verification and
independent replay/framing with 56 child targets and four lifecycle targets.

The actual shared-runtime parity test in
`tests/test_semantic_v8_orchestration.py` requires Torch and uses supplied
engineering decisions and child bytes. It must run in the hosted zero-skip
paired gate. This new test and the new ordinary orchestration lifecycle were
not executable in the local environment. Historical general CPU and paired
results are retained separately under `docs/evidence/`; they do not substitute
for a fresh run of this implementation.
